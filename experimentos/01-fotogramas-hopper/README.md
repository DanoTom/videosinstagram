# 01 · Fotogramas de estilo: "No hay nadie. Y sin embargo, algo mira."

Tres direcciones de arte para el mismo guion (basado en la entrega de El Reflejo sobre el efecto reflector),
cada una con dos momentos: el gancho (*Automat*, 1927) y un dato (*Night Windows*, 1928).

- **A · Revista**: papel claro, grotesca enorme, serif itálica, lámina con pie de obra.
- **B · Collage**: recortes con borde de papel, haz de reflector, tiras rasgadas, cinta, halftone.
- **C · Nocturno**: obra a sangre, tipografía fina, marco de enfoque de cámara ("algo mira").

```bash
python3 recortar.py   # recorte de la mujer de Automat → assets/automat-mujer.png
node render.mjs       # out/A1.png … out/C2.png y versiones ui-* con la interfaz de Instagram
```

Obras: Wikimedia Commons (dominio público en EE. UU.). La tira de ojos de B1 es de *Medusa* (Caravaggio), del experimento 00.
